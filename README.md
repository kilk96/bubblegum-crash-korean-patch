# 버블검 크래시! 한국어 패치

PC Engine HuCard 일본판용 비공식 한국어 패치입니다. 현재 v0.9.0은 전체 플레이 검수가 진행 중인 검수판입니다.

## 다운로드와 적용

1. [Releases](https://github.com/kilk96/bubblegum-crash-korean-patch/releases)에서 `bubblegum-crash-ko-v0.9.0.zip`을 내려받아 압축을 푸세요. 현재는 비공개 저장소의 초안 릴리즈로 준비되어 있습니다.
2. 직접 보유한 일본판 원본 ROM을 백업하고 아래 SHA-256(파일을 식별하는 해시 값)을 확인하세요.
3. **xdelta 3.2 armor 호환 패처**로 동봉된 `.xdelta` 파일을 원본에 적용하세요. 자세한 명령과 결과 파일 확인 방법은 ZIP 안의 `README.md`에 있습니다.
4. 패치 결과를 PC Engine 에뮬레이터에서 실행하세요. 확인한 실행 환경은 Mesen 2.2.1입니다.

지원 원본은 헤더 없는 일본판 524,288바이트입니다.

```text
원본 SHA-256: e96600058f35178c78a88eb9596678c973e0095ae8bd9cb060668065197f8895
결과 SHA-256: 73eb660ced1ce1b05c935e476129b956186048cd0339d30fc8ff03449306083b
```

원본 게임 파일은 포함되어 있지 않습니다. 기존 영문 패치나 다른 한글판에 덧씌우지 마세요. 구형 xdelta 패처는 적용에 실패할 수 있습니다.

## 게임 소개

『버블검 크래시!』는 동명의 OVA를 바탕으로 한 PC Engine용 어드벤처 게임입니다. 나이트 세이버즈의 일원인 네네를 중심으로 인물과 대화하고 현장을 조사하며 사건을 추적합니다. 이야기 진행 중에는 미니게임과 연구소 탐색·전투도 즐길 수 있습니다.

## 번역 범위와 확인 사항

- 대사와 번역된 선택 문구를 포함합니다. 인명 검색의 빈자리 표기도 교정했습니다.
- 대표 대사 화면과 검색·연구소 장면을 확인했습니다. 전체 경로·보스·엔딩의 최종 완주 검수는 진행 중입니다.
- 메뉴·전투·타이틀·크레딧 등에는 일본어가 남을 수 있습니다.
- 다른 빌드에서 만든 세이브스테이트의 호환은 보장하지 않습니다. 기존 세이브는 백업해 주세요.
- 연구소 랜덤 전투를 줄이는 선택적 치트는 ZIP 안의 README에서 안내합니다. 기본 패치에는 활성화되어 있지 않습니다.

## 권리와 글꼴

게임과 원본 글꼴의 권리는 각 권리자에게 있습니다. 한글 글꼴의 출처와 라이선스는 ZIP 안의 `FONT-NOTICE.txt`와 라이선스 문서를 확인해 주세요.
